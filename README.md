# Virtual Fitting Hub — Smart Digital Wardrobe

Luxury responsive frontend prototype based on the supplied project brief and palette.

## Included
- 3D Digital Twin profile builder (prototype)
- Virtual Try-On / Mix & Match
- Aggregated Wardrobe with filters
- Where to Buy / price comparison modal
- AI Stylist + weather mockup
- Outfit Randomizer
- Light/Dark mode with reversed foreground/background treatment
- Responsive desktop and mobile layout
- Palette: `#F7E9A2` `#F86C6D` `#9FD2E8` `#374785` `#24315E`

## Run
Open `index.html` in a browser or enable GitHub Pages for the repository.
